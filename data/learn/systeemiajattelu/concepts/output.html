output

Käsite · systeemiajattelu · peruskäsite · virtaus systeemistä ulos

Määritelmä

Output eli ulostulo on mikä tahansa materia, energia tai informaatio, joka siirtyy systeemistä sen ympäristöön rajan yli. Se on prosessin tulos — se, mitä systeemi tuottaa ja päästää ulos itsestään.

Output on järjestelmän näkyvä vaikutus ympäristöönsä. Se voi olla tarkoituksellinen tuote (esimerkiksi leivottu leipä, painettu kirja) tai sivutuote, jota systeemi ei aktiivisesti tavoittele (kuten hiilidioksidi, melu, lämpö). Systeemiajattelussa kaikki mikä ylittää rajan systeemistä ulospäin, on output — oli se sitten hyödyllistä, haitallista tai merkityksetöntä.

Output jaetaan kolmeen pääryhmään, jotka vastaavat inputin luokittelua:

  • Materia-output — valmis tuote, jäte, päästö, erite.
  • Energia-output — liike, lämpö, valo, sähkö, ääni.
  • Informaatio-output — viesti, signaali, data, päätös, käyttäytyminen.

Output on kriittinen käsite, koska systeemin olemassaolon oikeutus on yleensä sen outputissa: tehdas on olemassa, koska se tuottaa tuotteita; koulu, koska se tuottaa osaamista; sydän, koska se pumppaa verta. Outputin mittaaminen onkin usein ainoa keino arvioida, toimiiko systeemi tarkoitetulla tavalla.

Alkuperä

Output-käsite kehittyi rinnakkain inputin kanssa 1940-luvun kybernetiikassa. Säätötekniikassa output on järjestelmän mitattavissa oleva vaste, jota verrataan asetusarvoon. Bertalanffyn yleisessä systeemiteoriassa output on yhtä perustavanlaatuinen kuin input, ja systeemi määritellään nimenomaan input–output -muunnokseksi.

Järjestelmädynamiikassa Forrester kutsui output-virtausta outflowksi: virtaukseksi, joka poistuu varastosta. Varasto kasvaa, kun input ylittää outputin, ja kutistuu, kun output ylittää inputin. Tämä yksinkertainen yhtälö (ΔStock = Input − Output) on koko stocks-and-flows-mallinnuksen ydin.

Itäisissä perinteissä outputia vastaava käsite on karman hedelmä — teon vaikutus, joka palaa maailmaan. Siddha- ja ayurveda-kirjallisuudessa puhutaan malasta, kuona-aineista, jotka keho ja mieli poistavat, jotta järjestelmä pysyy terveenä.

Yhteydet muihin käsitteisiin

  • input — outputin vastakohta, systeemiin tuleva virtaus.
  • process — muuttaa inputin outputiksi.
  • state — output vaikuttaa ympäristön tilaan.
  • boundary — output ylittää tämän rajan ulospäin.
  • environment — outputin kohde.
  • feedback — outputista voi tulla uusi input.
  • behavior — systeemin output ajan funktiona.
  • emergent-properties — output voi olla emergentti ominaisuus.
  • stocks — varasto, josta output virtaa ulos.
  • flows — output on yksi virtaustyyppi.
  • requisite-variety — outputin monimuotoisuus Ashbyn lain mukaan.

Missä oppitunneissa käsitellään

Output tulee vastaan Systeemiajattelun perusteet -jakson ensimmäisessä kappaleessa, jossa käydään läpi peruskaava input → process → output. Syvällisemmin sitä käsitellään virtausmallinnuksen, palautejärjestelmien ja kyberneettisten silmukoiden yhteydessä, joissa output palaa inputiksi.

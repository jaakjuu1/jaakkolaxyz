input

Käsite · systeemiajattelu · peruskäsite · virtaus systeemiin

Määritelmä

Input eli sisääntulo on mikä tahansa materia, energia, informaatio tai signaali, joka siirtyy ympäristöstä systeemiin sen rajan yli. Se on systeemin ulkopuolelta tuleva virtaus, joka muuttaa systeemin tilaa tai ylläpitää sen toimintaa.

Input ei ole sama asia kuin syy. Yksittäinen input on virtauksen osa, joka kulkee yhteen suuntaan järjestelmän läpi. Kun puhutaan inputista, puhutaan siitä, mitä systeemi ottaa vastaan — ei siitä, mikä sen aiheuttaa. Esimerkiksi auringon säteily on input kasville, raaka-aineet ovat input tehtaalle ja kysymys on input keskustelukumppanille.

Käytännössä input jaetaan kolmeen pääryhmään:

  • Materia-input — aine, raaka-aine, polttoaine, vesi, ilma.
  • Energia-input — sähkö, lämpö, valo, liike-energia, kemiallinen energia.
  • Informaatio-input — data, signaali, viesti, palaute, ärsyke.

Inputin tunnistaminen on systeemianalyysin ensimmäisiä askeleita: ennen kuin voi ymmärtää, mitä systeemi tekee, on tiedettävä, mitä se saa.

Alkuperä

Input-käsite on peräisin 1940-luvun kybernetiikasta ja säätötekniikasta, jossa järjestelmiä alettiin kuvata mustana laatikkona, joka muuttaa syötteen (input) tuotokseksi (output). Norbert Wiener ja Ludwig von Bertalanffy muotoilivat ajatuksen 1940-luvun lopussa, ja se vakiintui yleiseen systeemiteoriaan 1950-luvulla.

Myöhemmin käsite levisi kahteen suuntaan. Säätötekniikassa input on täsmällinen signaali, jonka suuruus mitataan. Järjestelmädynamiikassa (Forrester, Meadows) input on virtaus — jatkuva tai jaksoittainen muutos systeemin tilaan. Stocks-and-flows-mallinnuksessa input on yksi kahdesta virtaustyypistä (toinen on output), ja sen suhde varastoon (state) määrää, kasvaako vai kutistuuko systeemi.

Itäisissä perinteissä vastaava ajatus esiintyy ayurvedan prāṇa-käsitteenä: elämänenergia virtaa sisään hengityksen, ravinnon ja aistimusten kautta. Siddha-lääketieteessä puhutaan sisään otetusta elinvoimasta, joka ravitsee kuoria.

Yhteydet muihin käsitteisiin

  • output — inputin vastakohta, systeemistä poistuva virtaus.
  • process — inputin muutos systeemin sisällä.
  • state — input vaikuttaa systeemin tilaan.
  • boundary — input ylittää tämän rajan.
  • environment — inputin lähde.
  • open-system — systeemi, joka vastaanottaa inputia.
  • closed-system — systeemi, jossa input on nolla.
  • feedback — outputista takaisin inputiksi muuttuva virtaus.
  • disturbance — ei-toivottu input.
  • control-parameter — input, jota voidaan säätää tarkoituksellisesti.
  • stocks — varasto, johon input kerryttää.
  • flows — input on yksi virtaustyyppi.

Missä oppitunneissa käsitellään

Input on ensimmäisiä käsitteitä Systeemiajattelun perusteet -jaksossa, jossa käydään läpi systeemin anatomia: input → process → output. Myöhemmissä oppitunneissa sitä syvennetään palautteen, virtausmallien ja kyberneettisten silmukoiden yhteydessä.
